# Shu

**CS20年 × Webコーディング × AI活用**

Webコーダーのしゅうと申します。強みは、20年の接客・カスタマーサポート経験に、モダンなWebコーディングの実装力とAI活用を掛け合わせている点です。

大手通信会社（ドコモショップ）やアマゾンジャパンでの在宅CSを通じ、複雑な仕様を予備知識のない相手へ伝わる言葉に置き換える力、トラブルを未然に防ぐ対応力を培いました。現在はその対人スキルをWeb制作に活かし、顧客と開発チームの間で認識をそろえ、こまめにすり合わせながら手戻りを防ぐ進行に貢献しています。

実務では Claude Code や Figma MCP などのAIツールを活用し、デザインデータからの初期実装を自動生成するなど着手を高速化しています。生成物を鵜呑みにはせず、動くコード・引き継げるコードとしての最終的な責任は自分が持つ前提で扱っています。

## ◆ 私ができること・強み

**顧客と開発チームの通訳**
20年のCS経験に、自分でコードを書ける知見を重ね、専門用語を顧客に、漠然とした要望を実装可能な形で開発側に、双方向に翻訳します。

**働きやすい空気をつくる**
傾聴と気配りでチーム内外のやり取りを円滑にし、関わる人が動きやすい雰囲気づくりに貢献します。長く続く関係を大切にします。

**こまめなすり合わせ**
作業を進める中で出てきた疑問や確認点は、ためこまずこまめに相談します。認識のずれは早めに解くほど小さく済むため、都度すり合わせながら進め、後からの大きな手戻りを防ぎます。

**要件もプロンプトも言語化**
曖昧な要望や仕様を精度高く言葉に落とし、同じ力でAIから狙った出力を引き出して着手を高速化します。

**引き継ぎ前提の設計**
BEM等の命名規則と部品のコンポーネント化で、他の担当者が読んで修正・追加しやすいメンテナンス性を重視します。

## ◆ 職務要約

**カスタマーサポート・接客業務（1998年9月〜2019年5月）**
20年以上にわたり、大手通信会社（ドコモショップ正社員）のサポート業務や、アマゾンジャパン合同会社（契約社員）での在宅カスタマーサポート等に従事。複雑な仕様の言語化、トラブルの先回り回避、クレーム対応を得意とし、この経験が現在のヒアリングと確実な納期管理の土台になっています。

**Webコーディング業務（2025年5月〜現在）**
デイトラのWeb制作コース・アドバンスコースを修了し、2025年5月にフリーランスとして独立。WordPress構築やLPの実装、Next.js / TypeScript / microCMS を用いたモダンなフロントエンド実装を行っています。運用担当者が更新しやすい設計（カスタムフィールドの活用、部品のコンポーネント化）を意識しています。

## ◆ 主要な制作実績（クライアント名は伏せ、業種で記載）

**保育園グループサイト（全70園規模）**
各園の情報の管理方法（掲載項目・検索や地図の要件・更新担当者の運用のしやすさ）をヒアリングを重ねて詰めながら microCMS を設計。一度で決め切らず往復してすり合わせ、運用担当者が無理なく更新できる形に落とし込みました。各園を1コンテンツとして一覧・詳細を動的生成し、条件による検索・絞り込み、住所からのGoogleマップ自動生成、リッチエディタのカスタムクラス設定を実装。（Next.js / TypeScript / Tailwind CSS / microCMS）

**採用LP（建築関係企業）**
https://shu-web.jp/uematsu-recruit/
Adobe XD のデザインカンプからのコーディング。スライダーやドロップダウンなど動きのあるパーツも含め、制作期間5日で納品しました。

**企業LP（実案件想定チャレンジ課題）**
https://shu-web.jp/jitsuanken-challenge/
Figma のデザインカンプをピクセル単位で再現。アニメーションの挙動も含めて納期より前倒しで提出し、修正なしで完了しています。

**禁酒サポートメディア（自社メディア・個人開発）**
https://sober-ai.com/
JavaScript による禁酒日数カウンター、Gemini API と連携して用語集からプロンプトを自動生成する機能を個人開発。

**Chrome拡張機能「習慣トラッカー」**
日本語版・英語版の2言語で Chrome ウェブストアに無料公開。企画から実装、ストア公開まで個人で行いました。
